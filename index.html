常见问题

关于试用、数据与上线，你想知道的都在这里。

试用期间需要付费或绑定信用卡吗？

不需要。注册即可开通 15 天全功能试用，无需信用卡，到期后数据保留 30 天，可随时升级续费。

可以使用自己的独立域名吗？

可以。绑定自有域名后自动签发并续期 SSL 证书，全站 HTTPS 访问，也可以直接使用我们提供的二级域名。

商城数据是否属于我们？能否导出？

商品、订单、会员等数据全部归你所有，支持随时一键导出为 Excel / CSV，也提供开放 API 与系统对接。

专业版起支持一键生成微信小程序并与 PC、H5 数据打通；旗舰版提供开放 API 与 App 端对接方案。
